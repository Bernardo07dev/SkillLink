# SkillLink 🚀
🔗 **[Link Deploy Vercel](https://skill-link-lemon.vercel.app/)**

## 📌 Resumo do Projeto

A **SkillLink** é uma plataforma inteligente criada para resolver um dos maiores desafios do futuro do trabalho: **como conectar talentos, competências reais e demandas de equipes em constante evolução**.

Usando dados a SkillLink permite:

- ✅ Mapear habilidades técnicas e comportamentais
- ✅ Encontrar rapidamente colaboradores com o perfil ideal
- ✅ Formar equipes de alto desempenho com base em competências reais
- ✅ Acompanhar projetos, progresso e liderança
- ✅ Identificar gaps que exigem reskilling ou upskilling

### 🎯 MVP Entregue

- **Dashboard de Projetos**
- **Dashboard de Times**
- **Filtros inteligentes** (status, área e habilidades)
- **Perfil do colaborador**
- **Interface moderna** (React + Tailwind)
- **Dados mockados em JSON** para simular o ambiente real

A plataforma foi construída pensando no cenário futuro onde **IA, automação e a economia da longevidade** exigirão que empresas entendam profundamente o potencial humano de suas equipes.

## ⚙️ Instalação do Projeto — Passo a Passo

### 1️⃣ Clonar o repositório

```bash
git clone https://github.com/usuario/skilllink.git
```

### 2️⃣ Acessar a pasta do projeto

```bash
cd skilllink
```

### 3️⃣ Instalar dependências

```bash
npm install
```

### 4️⃣ Rodar o projeto localmente

```bash
npm run dev
```

### 5️⃣ Abrir no navegador

```
http://localhost:5173
```
